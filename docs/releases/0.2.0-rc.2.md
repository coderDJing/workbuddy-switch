# WorkBuddy Switch Next 0.2.0-rc.2

本次候选预览版新增 Qoder CN 账号管理，并将各产品平台的导航与设置分开。

## 本版变化

- 新增 Qoder CN 桌面端与 Qoder CN CLI 的登录态认领、重命名、删除及账号切换。两端分别保存账号包，与 WorkBuddy / CodeBuddy 账号库互不相通。
- 切换前备份当前凭据，按整组文件写回并校验；写入失败时尝试整组回滚。桌面端运行中会先关闭、切换后重新打开，CLI 切换后需手动重开。
- 新增左侧平台栏，各平台只展示其支持的页面。Qoder 目前提供账号管理，WorkBuddy / CodeBuddy 保留关联会话、Token 统计和积分统计。
- 将外观、支持工具、备份与更新保留在全局设置；WorkBuddy / CodeBuddy 的权限检测、自动签到、CLI 自动轮换与限额监听移至平台设置。
- 兼容旧页面链接与原有平台选择，记住最近使用的平台。
- 合入三平台发布检查与构建修复，并迁移至仍受支持的 macOS 15 构建镜像。

## 更新通道

本版继续使用独立的 `preview` 更新入口，Beta / RC 安装可在应用设置中手动检查更新。正式版通道不接收本版，安装本版后也不会自动转入正式版通道。

Windows、macOS Apple Silicon / Intel、Linux 安装包、签名更新包与独立 CLI 由本版本的发布流程生成。npm registry 发布仍未启用。

## 验证与限制

- 本机已通过类型检查、108 项前端测试与 12 项 Qoder 核心测试；真实 WebUI 完成认领、去重、重命名、删除，以及隔离测试凭据的 CLI 往返切换与损坏账号包拒绝验证。三平台发布门禁结果以本版本关联的 GitHub Actions 为准。
- 两个真实 Qoder 账号之间的切换、桌面客户端关闭重启和 Qoder 的 Tauri 实机调用尚未完成验证。
- 目前仅支持 Qoder 国内版。账号包绑定当前机器及系统用户，不参与 WebDAV 同步；Qoder 本地会话历史不随账号隔离。

Qoder 凭据布局与切换思路参考 MIT 许可的 [JIUSHIQINGSHAN/qoder-switch](https://github.com/JIUSHIQINGSHAN/qoder-switch)，具体实现按本项目结构重写。
