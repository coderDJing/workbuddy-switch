# WorkBuddy Switch Next 0.2.0-beta.1

首个社区维护预览版，基于 WorkBuddy Switch v0.1.62，完整维护桌面 GUI、webui 与 CLI。

## 本版变化

- 新名称、蓝色 N 贝雷帽图标、独立安装身份与更新签名。
- 按账号 Token / 调用统计、账号排序与最近使用记录，限额台账定时刷新并保留上次结果。
- 跨账号会话置顶同步、创建时间保留，以及受客户端运行状态保护的陈旧会话归档。
- WebDAV 加密备份、选择恢复及多设备同步；增加凭据新旧判断、ETag 并发保护和预览内容校验。
- 扩充 JetBrains 系列及 Android Studio 支持，改善 Windows 客户端关闭、重开与认证写入保护。
- 分散签到调度，修复失败账号可能阻塞后续账号的问题。
- 改善会话悬浮窗的等待状态、生命周期、工程跳转及音效。
- 保留维护分支已有的一次性 CLI、认证事务锁、旧凭据防回滚及 GUI/CLI 状态同步。

共处理上游 18 个开放 PR，其中 14 个吸收或改造，4 个由已有等价实现覆盖。来源与贡献者见 [维护记录](https://github.com/coderDJing/workbuddy-switch-next/blob/main/docs/FORK-MAINTENANCE.md)。感谢原作者与所有 PR 作者，保留原项目版权与 MIT 许可。

## 安装与兼容

- Windows、macOS、Linux 安装包及独立 CLI 随本次 Release 提供；文件完整性可通过 SHA256SUMS 核对。
- Next 继续使用 `~/.wb-switch` 账号库。升级前正常退出旧版，避免旧版与 Next 同时写入。
- 应用安装名称为 WorkBuddy Switch Next，拥有独立应用标识。macOS 首次使用可能需要重新授予 App 管理或完全磁盘访问权限。
- Next 的更新配置独立存放，自动更新只接受 Next 的签名。预览版使用 `preview` 更新入口，下载包链接固定到对应版本。
- npm 包名已准备为 `workbuddy-switch-next`，包含旧命令 `workbuddy-switch` 别名；npm registry 发布尚待发布凭据配置。现在可使用 Release 中的独立 CLI。

## 验证范围

Windows 本机已完成签名 NSIS 构建、D 盘试装、隔离空账号 GUI 首页/设置页与独立 CLI 验证。108 项前端测试、853 项核心单测、核心集成测试、35 项 server 单测与 21 项 CLI 端到端测试、34 项桌面单测通过；严格 Clippy 通过。三平台远端结果以本版本关联的 GitHub Actions 为准。账号与 WebDAV 自动测试使用隔离数据；不代表所有真实账号、客户端版本及远端服务均已验证。本版为预览版，原仓库尚未解决的 Issue 未在本轮统一修复。

更新包已做 Next 更新签名；该签名与 Windows 开发者代码签名、Apple 公证属于不同机制。
