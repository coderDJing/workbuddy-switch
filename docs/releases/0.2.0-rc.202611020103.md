# WorkBuddy Switch Next 0.2.0-rc.202611020103

本版为更新检查卡住问题增加 RC 专用诊断日志，并避免设置页无限等待。

- 仅 RC 构建记录启动、桌面调用接收与分发、更新状态推送、托盘菜单刷新、更新源请求及耗时。正式版不创建或写入此诊断日志。
- 设置页检查更新最多等待 15 秒；若桌面调用没有返回，会显示超时提示并恢复按钮。该提示不表示后台检查被取消。
- 设置 → 自动更新增加「打开 RC 诊断日志」。日志位于 `~/.wb-switch/diagnostics/rc-debug.log`，最多保留当前 1 MiB 文件及一份轮转备份。
- 日志只记录命令名、阶段、耗时和状态，不记录调用参数、账号凭据、代理地址或密码、响应正文及原始错误内容。

继续沿用 RC.3 的 Qoder CN 桌面端 / CLI 账号管理、平台导航与全局 / 平台设置拆分。Qoder 真实双账号互切及桌面客户端关闭重启仍需实测。

以后仅发布 RC 与正式版，RC 使用上海时间版本号，版本脚本与 CI 拒绝 Beta / Alpha。

本版走 `preview` 预览更新入口，与正式版通道保持隔离。Windows、macOS Apple Silicon / Intel、Linux 安装包与签名更新清单以本次 Release 附件为准。
