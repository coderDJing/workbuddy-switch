# WorkBuddy Switch Next 0.2.0-rc.202611020952

本次 RC 改进 Qoder 账号管理，并修复 macOS 测试中的短暂锁竞争。

- 支持 Qoder 国内版与国际版的桌面端、CLI 账号；四个目标分别检测和保存登录凭据，账号包彼此隔离。
- 本机检测到的当前登录直接展示在账号列表中，可保存后切换；国内版与国际版使用官方图标。
- 账号识别不再仅凭显示名覆盖已有账号；切换前无法保存当前凭据时取消切换，写入前备份并在失败时回滚。
- Qoder 切换遇到短暂锁竞争时限时重试，持续占锁时仍拒绝并发切换。
- 新 RC 和 preview 更新入口发布成功后，清理旧 RC Release、标签以及 preview 中过期的附件；正式版和其他预发布类型不受影响。

Qoder 国际版尚未在真实客户端验证，国内版和国际版的真实双账号往返切换仍需实测。页面检测到本地凭据不代表凭据仍然有效；CLI 未生成独立凭据时无法认领 CLI 登录。账号包仅保存在本机，不参与 WebDAV 同步。

本版使用 preview 更新入口，与正式版通道隔离；各平台安装包和更新清单以 Release 附件为准。
